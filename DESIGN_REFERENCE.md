# MineLab product reference: LabLog

The LabLog App Store listing supplied for this project is used as a product reference for the broad information architecture: experiment records, calculations, and sample management in one focused lab utility.

MineLab will borrow the workflow idea, not copy LabLog's visual assets, code, text, or proprietary interaction details. The key differentiation is the execution timeline: a template creates a real experiment instance, each step has planned/actual time, and completing a step can move dependent steps.

Phase 0.1 therefore keeps the bottom navigation simple (`今日`, `实验`, `计算`, `样本`, `我的`) while making the Dashboard the execution center. Calculators and samples will be linked to experiment steps in later phases.
